**Status:** done (2026-10-28, PR #74 https://github.com/jmgirard/supplement/pull/74)

**Goal:** Let an author follow the publishing guide from an empty folder to a release with the R console, a web browser, and the Git pane of RStudio or Positron, with no GitHub command-line tool.
