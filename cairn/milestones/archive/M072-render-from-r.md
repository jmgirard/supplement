# M072: Render a site from the R console

**Status:** done (2026-10-28, PR #73 https://github.com/jmgirard/supplement/pull/73)

**Goal:** Let an author render the site, or run changed reports again and then render the site, with one R function and no terminal.

**Outcome:** Exported `render_supplement(reports = NULL, path = ".")` in `R/render-supplement.R`. It checks `path`, `reports` (names by `check_report_name()`, now in `R/add-utils.R` and shared with `add_report()`), `_quarto.yml`, and each `analyses/<name>.qmd` by exact letter case through `report_file_names()`; then runs the Quarto copy that `find_quarto()` picks, by full path, through `quarto_run()` (`system2()`, output to the console): each named report by name, then `quarto render`, then `quarto render` once more when `unpublished_figures()` finds a file of `figures/` missing from `docs/figures/`, printing what is still missing after that. It returns the commands it ran, restores the working folder, names a status-127 start failure, and runs no git. The `create_supplement()`, `add_report()`, and `check_tools()` messages, `rerender_steps` in `check_supplement()` rows, GUIDE.md's render steps (not its renv steps), NEWS, `_pkgdown.yml`, and DESIGN.md name it. Tests: `test-render-supplement.R` (mocked runner and lookups, plus four real renders through `render_quiet()`, which reruns a failed call once and logs it to standard error); `fake_quarto()` and `local_tools()` moved to `helper-tools.R`.
