# M050: Give a new site a reader README and a separate guide

**Status:** done (2026-10-24, PR #51 https://github.com/jmgirard/supplement/pull/51)

**Goal:** The first render of a new site leaves a short `README.md` for the people who read the site's repository, and the author guide in its own file, `GUIDE.md`.

**Outcome:** `inst/template/_README.md` is a reader page (placeholder citation, `Website:` line, contents, licenses). The new `inst/template/GUIDE.md` holds the old guide's author parts with every heading kept, and ends with `## Reference` (License ids, File names in `_supplement.yml`, Setup scripts). `quarto use template` (Quarto 1.10.19 skip list `kBuiltInExcludes`) and `create_supplement()` copy `GUIDE.md` under its own name. `_scripts/setup.lua` renames `_README.md` to `README.md` when none exists and otherwise removes it, so no `SUPPLEMENT.md` is written. `fill_repo()` writes the Pages address into `GUIDE.md` too. `check_supplement()` keeps its `SUPPLEMENT.md` placeholder key for sites made earlier. `index.qmd`, `_quarto.yml` comments, roxygen of `create_supplement()`, `check_supplement()`, and `write_dockerfile()`, README.md, the publishing vignette, NEWS, and DESIGN.md name the new files. Tests: "setup keeps an existing README.md and writes no SUPPLEMENT.md" (three cases, second render each; failed on main's `setup.lua` at the no-`SUPPLEMENT.md` assertion), `GUIDE.md` in `template_tracked` and in the `quarto use template` file list, `GUIDE.md` in both repo tests.

**Decisions:** D-024 (supersedes D-006's README clause), chosen at the plan gate: the guide in its own file over package docs only and over one guide file. The plan chose the name `GUIDE.md` over keeping `SUPPLEMENT.md`.

**Review:** Plan audit 10 findings, all fixed; claim audit 45 claims, 4 corrected.
