# M009: release_supplement() raises the version and prints release commands

**Status:** done (2026-10-18, PR #9 https://github.com/jmgirard/supplement/pull/9)

**Goal:** Export `release_supplement()`, which raises the site version in `_supplement.yml` after `check_supplement()` finds no problem and prints the commands that make the release.

**Outcome:** The template's `_supplement.yml` has `version: ""` under `supplement:`. `read_version()` and `is_version()` (whole-text `\A…\z` match of three whole numbers with no leading zero) live in `R/supplement-yml.R`. `write_citation()` and `write_zenodo()` write `version` when it is not empty and stop with `supplement_error_version` otherwise. `write_utf8()` now writes through `write_checked()`. `R/release-supplement.R` exports `release_supplement(bump, path = ".")`. The `bump` argument is a word or a greater version, with its attributes dropped. The function refuses a linked, unreadable, or unwritable output (or a missing one in an unwritable folder) before any write, then runs `check_supplement()`. It stops on any problem except the `CITATION.cff` DOI row, or on skipped checks. Then it replaces only the `version:` value (`yaml_replace_lines()` and `yaml_replaced()` in `R/yaml-insert.R`, D-011), writes both outputs, and prints seven git and `gh` commands it never runs. `write_release_files()` puts back each file whose bytes changed and removes each made output with `file.remove()` on an error or an interrupt. README, `_README.md`, NEWS, the help page, and DESIGN.md describe it.

**Decisions:** D-011 (a one-line value change follows D-010's text-edit rule). Milestone-local (from RR01): the snapshot-and-restore design stays; three of the four returns came from criterion wording; the next review floored a return only on a listed test or stated rule.
