# M074: Tag the release on the branch that holds it

**Status:** done (2026-10-28, PR #75 https://github.com/jmgirard/supplement/pull/75)

**Goal:** The release address that `release_supplement()` prints tags the author's current branch, for more forms of a GitHub `origin` url.

**Outcome:** `release_address()` adds `&target=<branch>`, percent-encoded by `url_encode()`, when the site's checkout is on a branch whose name is valid UTF-8. It accepts https/http (user, port, `www.`), `ssh://` (also `git+ssh://`, `ssh+git://`, host `ssh.github.com`, user, port), and scp-like `[<user>@]github.com:` origins, the host in any case, an owner with `_`, a `.git` in any case, and one trailing `/`. It refuses names `.`, `..`, and `.git`. `origin_url()` reads `git remote get-url --push origin`. `release_branches()` and `symbolic_ref()` in `R/check-supplement.R` read the full refs of HEAD and `refs/remotes/origin/HEAD` through `git_run()`. `report_release()` names the branch in the push-first text and the Releases-page steps, and warns when the branch is not origin's default. Help, README, template GUIDE.md, the publishing vignette, NEWS, and DESIGN follow. Tests: url tables through `release_address()` with one end-to-end case each, the push-url test, branch, detached-HEAD, same-named tag, local `origin/main`, and non-UTF-8 branch cases.

**Decisions:** D-038 (the address names the current branch and reads the push url; narrows D-036). Implement: a byte encoder `url_encode()` over `utils::URLencode()`, which would need utils in Imports.
