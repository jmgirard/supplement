# M030: Each report shows the R setup that made its stored output

**Status:** done (2026-10-21, PR #31 https://github.com/jmgirard/supplement/pull/31)

**Goal:** The template's example report and each report that `add_report()` writes end with a section that prints the R and package versions of its render, so that a page's stored output records the setup that made it.

**Outcome:** `inst/template/analyses/example.qmd` ends with a "Computing environment" section: a short paragraph and a collapsed callout whose `session-info` chunk (`cache: false`, wrapped in `local()`) prints `sessioninfo::session_info()` when sessioninfo is installed and `utils::sessionInfo()` otherwise. The chunk shows each spelling of the `USERPROFILE` and `HOME` folders (normalized, Windows short names, either slash, case-insensitive on Windows) as `~`, longest first, matching only a whole folder that starts a path. Folders outside the home folder show in full. `report_lines()` in `R/add-report.R` appends the same lines, read from the installed template by `environment_section()`. The template guide explains the section, the paths it shows, and how to copy it into an older report and render that report by name. README.md, NEWS.md, the `add_report()` help, and DESIGN.md mention it. sessioninfo joins Suggests, and the CI skip list counts a missing sessioninfo as a missing tool (D-019). Tests render the example twice (once with sessioninfo hidden by a chunk in the test's copy of the report), check the R and knitr versions and that no home path is on the page, run the chunk for each branch and for prefix, linked, and LAPACK-path homes, and compare the stub's section bytes with the example's.

**Decisions:** AC1 was amended at the user's stop to render with `QUARTO_R` unset, read the knitr version from `R_HOME/bin/Rscript`, and accept `knitr_1.52` and `knitr  1.52`. D-019 promotes the sessioninfo dependency.
