# M037: Report missing tools before site setup

**Status:** done (2026-10-23, PR #38 https://github.com/jmgirard/supplement/pull/38)

**Goal:** Authors can see which tools a supplement site needs are missing before a first render fails.

**Outcome:** New exported `check_tools()` in `R/check-tools.R` returns, invisibly, a data frame (`tool`, `status`, `detail`) with rows `Quarto`, `knitr`, `rmarkdown`, `git`, `gh`, `GitHub account`, `Zenodo account`, and prints one cli line per row through `tool_lines()`. Statuses: `found`, `not on path`, `too old`, `missing`, `reminder`. `find_quarto()` tries the system path (`tool_which()`, `Sys.which()`), then the file `QUARTO_PATH` names, then `editor_quarto_paths()`: the RStudio and Positron copies for macOS, Windows (`PROGRAMFILES`, `LOCALAPPDATA`), and Linux, each path sourced from RStudio's CMake rules, Positron's build files, a forum post, or this Mac's install. `quarto_version()` follows a link with `normalizePath()`, reads `share/version` beside `bin/`, accepts only ASCII digits, dots, and spaces before `rawToChar()`, and catches the `numeric_version()` warning for a part too big for an integer, so such files read as "version unknown". A version below `quarto_minimum` (1.4.0, the extension's `quarto-required`) is `too old`, which wins over `not on path`; an off-path `detail` says a terminal `quarto render` can miss the copy. `package_version_text()` reads DESCRIPTION without loading. `create_supplement()` runs `tool_problems()` after the copy and adds one closing-message line per `missing`, `too old`, or `not on path` row plus a `check_tools()` line; errors and warnings in the lookups give no line. No tool is run; `git_run()` keeps the package's one call of `system2`, and `Sys.which()` starts a shell that runs `which` on Unix. Help pages, README, NEWS, and DESIGN.md describe it. Tests: 16 in `test-check-tools.R` (mocked lookups, temporary installs, a link case that skips on Windows) and 2 in `test-create-supplement.R`.

**Decisions:** none cross-cutting. Question set: a function that `create_supplement()` also runs and never stops on; Quarto looked for on the path, in `QUARTO_PATH`, and in editor folders; accounts listed as reminders. Plan chose reading `share/version` over running `quarto --version`, and the name `check_tools()`. AC2 amended from "will not find" to "can miss", after the claim audit showed R's path can differ from a terminal's (two re-audits).
