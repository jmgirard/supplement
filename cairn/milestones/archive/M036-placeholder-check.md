# M036: The release stops on template placeholders

**Status:** done (2026-10-22, PR #37 https://github.com/jmgirard/supplement/pull/37)

**Goal:** `check_supplement()` gives a `"placeholder"` row for each template placeholder listed in AC1 to AC3 that a site still holds, so `release_supplement()` stops before it writes `CITATION.cff` and `.zenodo.json` from template values.

**Outcome:** `check_placeholders()` in `R/check-supplement.R` runs last in `check_supplement()`. `placeholder_values()` gives one `_supplement.yml` row naming each of `paper-title`, `citation`, `contact`, and `authors` (an entry with a template author's `family` and `given`) that equals the installed template's value, read through `template_supplement()`, after `clean_space()`. A value that is not one text value, or an empty template value, never counts. `placeholder_line_rows()` gives one row per file of `placeholder_lines` (`_quarto.yml` `href: https://github.com/OWNER/REPO`, `index.qmd` `## Before your first commit`, the two license files `Copyright (c) YEAR AUTHORS`, and `README.md`, `SUPPLEMENT.md`, and `_README.md` `Website: https://OWNER.github.io/REPO/`), ends trimmed of spaces, tabs, and CR. `plain_lines()` turns a missing path, a folder, or any read error of `read_text_lines()` into no lines. `placeholder_example_rows()` compares `analyses/example.qmd` and `data/example.csv` with the template's through `report_hash()` (CR LF read as LF), and skips a file over twice the template's size. Each file has its own problem text. `release_supplement()` is unchanged: every such row stops it. `?check_supplement`, the NEWS bullet, the "It finds" lists in `README.md` and the template guide, and DESIGN.md state the check. Tests: 12 new tests in `test-check-supplement.R`, the real-check release test, and `fill_placeholders()` in `helper-files.R`, called before any render or stored hash in the first check test, `renv_site()`, and `checked_site()`.

**Decisions:** none cross-cutting. The plan chose a check row over a separate release stop, read the `_supplement.yml` values from the installed template, and counted the example files only while their text equals the template's (question set). `write_citation()` and `write_zenodo()` keep accepting placeholders (question set).

One four-lens pass, 24 findings: 10 fixed, 1 follow-up (the new row "Match example files after editor saves"), 12 rejected (6 false, 3 style, 2 planned change, 1 edge), 1 noted; no review return.
