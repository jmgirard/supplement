# M005: Metadata writers for CITATION.cff and .zenodo.json

**Status:** done (2026-10-18, PR #5 https://github.com/jmgirard/supplement/pull/5)

**Goal:** Export `write_citation()` and `write_zenodo()`, which write `CITATION.cff` and `.zenodo.json` from the template's `_supplement.yml`.

**Outcome:** The package's first R code. `R/supplement-yml.R` reads `<path>/_supplement.yml` with every YAML sequence read as a list, checks it, and cleans each text value (runs of spaces and line breaks, Unicode ones included, become one space; ends trimmed). `write_citation()` writes CFF 1.2.0: title "Supplemental materials for: " plus `paper-title`, authors with `family-names`, `given-names`, URL ORCID, affiliation, `doi` from `concept-doi` then `version-doi` (prefix `doi:` or `http(s)://(dx.|www.)doi.org/` removed, form checked), and `license` as the code and content SPDX ids; every value double-quoted. `write_zenodo()` writes title, `upload_type` "software", description from `citation`, creators "Family, Given" with bare ORCID, and the content license in lowercase. Empty values are left out; `overwrite = FALSE` refuses an existing file, link, or folder of that name. Errors are `supplement_error` plus one of `_argument`, `_no_metadata`, `_no_map`, `_missing_field`, `_field_type` (a list, number, or true/false where text belongs), `_authors`, `_author_name`, `_orcid` (form and ISO 7064 check digit), `_doi`, `_file_exists`. Template authors use `family:`/`given:`; `_README.md` gained a "Citation files" section. Imports cli, jsonlite, yaml. 57 tests, 536 expectations; 38 planted defects each failed a test.

**Decisions:** D-009 (Imports). Milestone-local: concept DOI first in CITATION.cff, `upload_type` "software", `overwrite = FALSE` by default, Markdown passed through unchanged, content license only in `.zenodo.json`.

**Review:** two passes, three reviewers each, plus two claim audits (10 claims corrected). One defect return: a top-level scalar or list in `_supplement.yml` gave a base error, not `supplement_error_no_map` (AC4). 43 findings: 27 fixed on the branch (YAML numbers and booleans, one-item sequences, ORCID check digit, DOI form, quoting, argument and link checks among them), 5 to rows (new "metadata value checks" and "badge DOI form"; "docs site and walkthrough" and "license footer" widened), 11 rejected with reasons. The "metadata writers" row graduated.
