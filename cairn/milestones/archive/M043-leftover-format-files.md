# M043: Name leftover format files in _freeze

**Status:** done (2026-10-23, PR #44 https://github.com/jmgirard/supplement/pull/44)

**Goal:** The `"stale-output"` row of `check_supplement()` names each stored output file that does not match its report, so that an author can find and delete the file of a format that the report no longer renders.

**Outcome:** `check_stale_output()` in `R/check-supplement.R` keeps the state of each read `.json` file and names the files whose `hash` differs, by `_freeze/analyses/<name>/execute-results/<file>` paths in `sort_bytes()` order through `show_text()`, joined by `, `. When a file cannot be read, the "cannot be read" text names only those files. When every hash can be read and another file matches the report, a format hint says that the named files can be from a format the report no longer renders. If so, delete them, render the whole site, and commit the report with `_freeze/`, `docs/`, and `figures/`. If not, take the render steps (`rerender_steps`). The help item and the NEWS.md `check_supplement()` bullet state the rules. Tests: AC1 cases (a) to (f), a byte-order test that sets `en_US.UTF-8`, AC2 cases (a) to (d), and a Quarto render test that drops `docx` from a report. The test shows that `docx.json` is kept, that the row stays after a full render, and that after the delete the row is gone.

**Decisions:** Plan gate: name the files over skipping the formats a report does not render (no YAML format reading, never hides stale output). User choices at stops: the hint's commit list adds `figures/`, and at the third review return AC4 was narrowed so that the help item need not state the `, ` join.

**Review:** Criteria audit at plan (full mode): 9 findings, then 3 on the re-check, all fixed. Claim audit: 20 claims, 5 corrected. Four four-lens passes found no correctness bug. There were three defect returns (AC4 help "if not" branch; AC2 (b) fixture `[1` parsed; AC4 `, ` join, descoped) and three amendment returns (AC1 twice, AC4 once), each re-audited by a fresh reader. Fix-now items covered byte-order coverage, `show_text()`, help and NEWS wording, a render-test check, and test comments. Planned-change rejects: the hint can name a live format's file after a `--to` render, `git add figures` on a site without `figures/`, and guides that do not cover kept format files. `devtools::check()` 0/0/0, and CI passed on all six jobs. Graduated "Name leftover format files in _freeze". New row: "Advise deleting unreadable format files".
