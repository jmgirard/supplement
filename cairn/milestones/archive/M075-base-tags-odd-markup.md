# M075: Read base tags and odd markup in pages

**Status:** done (2026-10-29, PR #76 https://github.com/jmgirard/supplement/pull/76)

**Goal:** `check_supplement()` reads the links of pages with a `<base>` tag, odd comment ends, `</` markup, or escaped script text by the stated HTML Standard rules.

**Outcome:** In `R/check-supplement.R`, `tag_links()` gives the raw href of the first `<base>` tag with an href as the attribute `base` and leaves base tags out of the links; `page_values()` cleans it with the new `link_text()`; `page_links()` sorts it with `base_kind()` ("page" for an empty, `#`, `?`, `data:`, or `javascript:` value; "away" for another scheme or a leading `/`, leaving the relative links unchecked; else "local") and `base_address()`, and gives each link a `targets` path that `check_links()` passes to `link_ok()`; under a local base a `#` or `?` link resolves to the base address. `html_skipped` ends a comment at `<!-->`, `<!--->`, or the first `-->` or `--!>`, removes `</` with a non-letter to the next `>`, and reads end tags through their attributes. The new `html_script_body` gives script text the escaped and double escaped states, as unrolled possessive loops with one class lookahead per ordinary `<` and rare forms in an outer loop. It reads main's sizes for `<` runs, 20 MB of HTML-like text, and dash runs; millions of `</`, `<!`, or (after `<!--`) `<s` or separate `-` runs reach the PCRE limit sooner (2M `</a` warns where main read 4M). Help page, NEWS, DESIGN.md (link check text; "Link reader limits" entry with the base cases), and the source note `cairn/references/whatwg-html.md` (HTML Standard 2.4.3, 4.2.3, 13.2.5) state the rules. Tests: one or more per criterion, a margin test (3M `<`, 5M dashes), and a pin for the `->`, `<s`, and `<!` branches.

**Decisions:** milestone-local: a row under a base names the link as the page writes it; links and bases that start with `/` stay unchecked (the site path is unknown); empty links under a base stay unchecked. M021's choice to keep `<!-->` and `<!--->` as stated limits is replaced. D-017 (base R reader) stands. No D-entry.
