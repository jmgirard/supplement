# M022: The link check reads every page once and refuses links out of docs

**Status:** done (2026-10-20, PR #23 https://github.com/jmgirard/supplement/pull/23)

**Goal:** `check_supplement()` reads each page in `docs/` once, pages in hidden folders included, and gives a `broken-link` row for a symbolic link in `docs/` whose target is outside `docs/`.

**Outcome:** `check_links()` in `R/check-supplement.R` lists `docs/` with `docs_entries()`, a queue walk over `list.files(all.files = TRUE, no.. = TRUE)` that lists a linked folder (`is_link()`, junctions included on Windows) and does not enter it. `docs_root()` normalizes `docs/` once; `outside_links()` and `in_docs()` give one row per link whose existing target resolves outside it ("It is a link to a place outside docs/, so the published site does not have its target."), paths built from the normalized root so an unresolved path counts as inside, case ignored on Windows through `utf8_lower()`. An outside `.html` link is not read as a page. Pages and outside rows sort by byte keys (`Encoding(keys) <- "bytes"`, radix order). `link_ok()` takes `root` and fails a link when any existing part of its path, the added `index.html` of a folder link included, resolves outside `docs/`; with no link in `docs/` it skips that test. `is_reparse_point()` in `R/supplement-yml.R` now takes a vector and lists and normalizes each parent folder once (it had listed the parent per path). The help page, NEWS, README, the template `_README.md`, and DESIGN.md state the rules. CI fails a test skipped with "cannot make a symbolic link here". Tests: one per criterion, a folder `index.html` behind an outside link, relative link targets and a hidden-folder link, a page name that is not valid UTF-8 (runs where the file system holds one), and the per-folder `is_reparse_point()` rules with OS-dependent expectations; on Windows the tests make folder links as junctions.

**Decisions:** milestone-local: a link whose target is inside `docs/` gives no row; linked folders are not entered (falsified by a site whose pages exist only behind a linked folder inside `docs/`); the AC3 row text above. No D-entry.
