# M007: add_report() and add_data() list new site files

**Status:** done (2026-10-18, PR #7 https://github.com/jmgirard/supplement/pull/7)

**Goal:** Export `add_report()` and `add_data()`, which add an analysis report or a data file to a site and list it in the site's configuration.

**Outcome:** `R/add-report.R` exports `add_report(name, title, description = "", path = ".")`. It writes `analyses/<name>.qmd`, with the title and description double-quoted and a `setup` chunk with `set.seed(2026)`, and adds `href` and `text` as the last item of the Analyses menu under `website: navbar: left:` or `right:`. `R/add-data.R` exports `add_data(file, description, path = ".")`. It copies `file` byte for byte to `data/<base name>`, or copies nothing when `file` is already that file, and adds `file` and `description` as the last `data` item under `supplement:`. `R/yaml-insert.R` finds a block-style list by indent and key and inserts lines after its last content line. It keeps each line's ending, the final line break, and a byte order mark. It escapes control characters, YAML 1.1 line breaks, U+FEFF, U+FFFE, and U+FFFF, and re-reads the whole file with the yaml package before any write (D-010). `write_checked()` treats an error, a warning (a full disk), or a short file as failure and restores the old bytes. Checks run before the first write: the name and base-name rules (no trailing line break; no base name with `_` at both ends), UTF-8 text, Unicode white space, links at `analyses/`, `data/`, or `data/<name>`, letter-case clashes, a stale `_freeze/analyses/<name>`, and file types the template's `.gitignore` blocks. The two not-found errors are base R conditions with a cli header, so the lines to add by hand keep their indents. The template's home page lists `analyses/*.qmd` through a Quarto table listing, and `example.qmd` has a description. README, the help pages, NEWS, `_README.md`, and DESIGN.md describe both functions.

**Decisions:** D-010 (text insertion with a yaml re-read). Milestone-local: base R conditions for the not-found errors; `copy_file()` and `write_bytes()` wrappers so tests can mock them.
