# M064: Compare renv.lock with report records

**Status:** done (2026-10-27, PR #65 https://github.com/jmgirard/supplement/pull/65)

**Goal:** `check_supplement(renv_lock = TRUE)` gives a `"renv-mismatch"` row for each report whose stored output names an R or package version that differs from `renv.lock`. `release_supplement()` does not run this check (D-032).

**Outcome:** `check_supplement()` has the argument `renv_lock = FALSE`. When it is `TRUE`, `check_renv_lock()` in `R/check-supplement.R` runs after `check_stale_script()`. `lock_versions()` reads `renv.lock` as UTF-8 bytes, skips a BOM, and names each record by its `Package` text, else by its key. It refuses a repeated key, as `read_lockfile_versions()` does. `stored_versions()` reads the text that `stored_markdown()` gives. That function is new and is now shared with `stored_script_hashes()`. `stored_versions()` reads the sessioninfo table after a `─ Packages` or `- Packages` rule, at its header's column positions, so a `!` column does not shift it. It also reads the sessioninfo `version` setting line, the first `utils::sessionInfo()` line in R's version-string form, and the two package lists, wrapped lines included. It drops a line end's CR. Lines with ANSI codes or a `## ` prefix are not read. `version_diffs()` compares versions as `package_version()` values, so a version that cannot be read is not compared. A report gets one row that names the files, then R and each package in byte order, each version once, with the `renv.lock` value. The row gives restore-and-render or snapshot steps, plus the old-format hint of `"stale-script"`. A `renv.lock` that cannot be read gets one row of its own. A missing one gives a skip message. `stored_json()` now marks its text as UTF-8, so a Latin-1 locale reads `─`. The help of both functions, NEWS.md, README.md, GUIDE.md (its renv part and check list), the publishing vignette, and DESIGN.md describe the check. Tests read real sessioninfo output under both rules and real `utils::sessionInfo()` at width 40. Row tests check exact text and many no-row cases. Other tests cover a CR LF file, a Latin-1 locale, 13 unreadable-lock forms, a Quarto render, and a release that goes ahead.

**Decisions:** D-032 (the comparison is opt-in, and the release does not run it), chosen at the plan over a check that always runs, whether or not it stops the release. The plan also chose to compare the R version as well, to read sessioninfo columns by header position, and to leave prefixed and colored lines unread.
