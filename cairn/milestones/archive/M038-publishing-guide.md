# M038: Write a first-time publishing guide

**Status:** done (2026-10-23, PR #39 https://github.com/jmgirard/supplement/pull/39)

**Goal:** A first-time author can follow one guide from an empty folder to a site served by GitHub Pages and archived on Zenodo with a DOI.

**Outcome:** New vignette `vignettes/publishing.Rmd` ("Publish a supplement site"; `VignetteBuilder: knitr`, with knitr and rmarkdown already in Suggests) in ten numbered steps: pak and `check_tools()`; a public GitHub repository with no README, `.gitignore`, or license, cloned; `create_supplement(repo =)` in the clone; the first `quarto render`; commit and `git push -u origin HEAD`, with the git identity lines and `gh auth login` plus `gh auth setup-git` for sign-in; Pages from the pushed branch's `/docs`; Zenodo Linked accounts and the repository switch, each step linking its GitHub Docs or Zenodo page; replacing the placeholders `check_supplement()` reports (the example report with its `_freeze/analyses/example/`, keeping the example figure until a report saves its own, and the README citation); `release_supplement("major")` and its printed commands; DOIs into `_supplement.yml`, `write_citation(overwrite = TRUE)`, render, and push. A last part gives the rule for a changed report: render it by name, render the whole site, then commit it with `_freeze/`, `docs/`, and `figures/`. Only plain `r` and `sh` fences, so a build runs no code. `tests/testthat/test-publishing.R` runs the local steps in a temporary git repository: the first commit holds `docs/index.html` and `docs/.nojekyll`, a full render alone keeps an old printed value while a render by name and a full render show the new one, and a version DOI gives its badge. README.md "Start a new site" links the guide; one NEWS bullet.

**Decisions:** none cross-cutting. Question set: this candidate was chosen. Plan chose a vignette over a README.md or template-guide part (both already long, and the template guide becomes the site's public README), and plain fences over `eval = FALSE` chunks. The GitHub and Zenodo pages read on 2026-10-22 state no private-repository limit, so the guide claims none and uses a public repository.
