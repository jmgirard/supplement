# M059: Flag a missing _scripts/report.R file

**Status:** done (2026-10-26, PR #60 https://github.com/jmgirard/supplement/pull/60)

**Goal:** `check_supplement()` gives a `"missing-script"` row when reports in `analyses/` name `_scripts/report.R` and the site has no such file, so `release_supplement()` stops before it archives reports that cannot be rendered again.

**Outcome:** `check_missing_script()` in `R/check-supplement.R`, under a "Shared report code" section before Links, runs after `check_leftover_output()`. When `file.exists()` is FALSE for `_scripts/report.R` or it is a folder, it reads each report from `analysis_reports()` with `read_report_lines()`, and `names_script()` finds a line where `_scripts` comes before `report.R`, neither with an ASCII letter, digit, `_`, or `.` before it nor after `report.R`. The two names are found with separate `regexpr()`/`gregexpr()` searches because one `.*` pattern passed PCRE's match limit on a 5 MB line. One row on `_scripts/report.R` names the reports in byte order with `quote_path()`, `show_text()`, and `sort_bytes()`, and says to copy the file from `system.file()` or restore it, make `_scripts` or move what is in the way, and commit it. A site made before M058 gives no row when its reports do not name the file. The help page states the limits (included files, other line forms, two-line calls, letter case, subfolders, unreadable reports, Windows file links, case-ignoring disks). README.md and GUIDE.md list the row, NEWS.md has a bullet, and the `add_report()` help, GUIDE.md "Shared report code", and the M058 NEWS bullet now say the check looks only at whether the file exists. DESIGN.md gained the architecture lines and the git-ignored case under "Release check edge cases". Tests: missing, folder, link (not on Windows), 5 MB line, end-of-line, order cases, byte order with `"` escaping, and seven lines that must give no row.

**Decisions:** none promoted. The plan chose a row only when a report names the file (pre-M058 sites lack it) and one row on the file rather than one per report.
