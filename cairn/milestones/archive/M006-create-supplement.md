# M006: create_supplement() makes a site from the template

**Status:** done (2026-10-18, PR #6 https://github.com/jmgirard/supplement/pull/6)

**Goal:** Export `create_supplement()`, which makes a new site folder from the package's template without the Quarto command-line interface.

**Outcome:** `R/create-supplement.R` exports `create_supplement(path, repo = NULL)`. It copies the installed template (`template_path()`), with hidden files and top-level `docs`, `_freeze`, and `_site` left out, into a new or existing folder, using `copy.mode = FALSE`. Trailing separators are dropped first, but a root such as `/` or `C:/` keeps its separator. A file, folder, or link at any template path, or a link where a template folder goes, stops the call before any write (`supplement_error_file_exists`). A failed folder, copy, or `repo` write gives `supplement_error_write` and removes what the call made, the missing parents of `path` included. `repo` (an owner of 1 to 39 letters and digits with single hyphens, and a name of 1 to 100 of `[A-Za-z0-9._-]` that is not `.` or `..`) fills `OWNER/REPO` in `_quarto.yml` and the Pages address in `_README.md`, with a lowercase owner and the root address for a `<owner>.github.io` name. Other classes: `_argument`, `_repo`, `_not_folder` (an existing file or a broken link). `_gitignore` and `_README.md` keep their names for the first render (D-004, D-006). `path_occupied()` and `is_link()` in `R/supplement-yml.R` are shared with `check_overwrite()`. Roxygen markdown is on, so the writers' help pages render lists and links. README gives the R route and an install line. 18 tests, including a render in a folder that holds `README.md` and `.gitignore`.

**Decisions:** none promoted. Milestone-local: R copy over calling `quarto use template`; renames left to the first render; a link at any template path is a conflict.

**Review:** two passes, three reviewers each, plus two claim audits (37 and 32 claims, 5 and 3 corrected). One defect return: `create_supplement("file/")` gave `_write`, not `_not_folder` (AC3). Of 36 findings, 25 were fixed on the branch: read-only copies, unclassed `fill_repo()` errors, the loose `repo` pattern, stray template files, a linked `data` folder writing outside `path`, and tests that passed with defects present. A new copy-failure test then found an empty file left after a failed `file.copy()` (fixed). 8 were rejected as false or style. 3 went to the "Windows check" row (links and separators on Windows). The "scaffolding functions" row stays open for M007.
