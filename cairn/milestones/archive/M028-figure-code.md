# M028: The template saves paper figures safely in more setups

**Status:** done (2026-10-21, PR #29 https://github.com/jmgirard/supplement/pull/29)

**Goal:** A new site's first render publishes the example figure, and the example's figure code works with `execute-dir: project`, a failed plot, a file named `figures`, and upper-case file extensions.

**Outcome:** The template ships `inst/template/figures/bootstrap-means.png` (D-018), so one full render of a new site gives `docs/figures/bootstrap-means.png` with the same bytes. In `analyses/example.qmd`, the `data` and `save-figure` chunks each set `site <- Sys.getenv("QUARTO_PROJECT_DIR", "..")`. The `save-figure` chunk stops when `figures` is a file and defines `save_png(file, draw, dir = figures)`: it refuses a `draw` that is not a function and a folder at the target, draws into a hidden `.save-*.png` in `figures/`, closes that device and makes the earlier one current, and renames the file into place. `_gitignore` spells the `analyses/` PNG and PDF rules with bracket patterns and ignores `.save-*.png`. The site README "Paper figures" section, NEWS.md, and DESIGN.md describe it. Tests in `test-template.R`: first render, both `execute-dir` setups, the code run by hand, a failed plot, a folder target and a non-function `draw`, a file named `figures`, and the ignore rules in two `create_supplement()` sites with `core.ignorecase=false` (`expect_figure_rules()`, `chunk_code()`, `folder_md5()` in `helper-template.R`). The two png tests skip on CRAN, and CI fails on their skip reason.

**Decisions:** D-018 (ship the example figure). The example finds the site through `QUARTO_PROJECT_DIR`, not the `here` package or knitr's `root.dir`.
