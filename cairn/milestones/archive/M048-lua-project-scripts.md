# M048: Run the template scripts without Deno

**Status:** done (2026-10-24, PR #49 https://github.com/jmgirard/supplement/pull/49)

**Goal:** A render of a site made from the template runs its two project scripts in Lua through Pandoc, so the render starts no Deno process and the macOS Deno crash (exit 139) cannot fail it there.

**Outcome:** `inst/template/_scripts/setup.lua` and `nojekyll.lua` replace the `.ts` scripts, and `_quarto.yml` names them; Quarto 1.10.19 runs each as `pandoc --from markdown --to plain --lua-filter <script>` with `cwd` set to the project folder. `setup.lua` uses names relative to that folder, reads and writes bytes, counts a path as existing unless `io.open()` fails with error 2, appends only the new `.gitignore` lines (mode `ab`), and stops the render through `assert()` on a failed read, rename, remove, or write (Pandoc exits 83, Quarto prints "Error running filter '_scripts/setup.lua'"). `nojekyll.lua` reads `QUARTO_PROJECT_OUTPUT_DIR` through `pandoc.system.environment()` and opens it relative to the project folder, so Lua's code-page file calls never see a non-ASCII site path on Windows. Tests in `test-template.R`: a full render logs both `--lua-filter` lines and no `deno run` line; each setup case byte for byte on a small no-R project, with a `.gitignore` that holds Quarto's own two lines; a second render; a `_gitignore` folder and a read-only `.gitignore`; a render under `é`; `nojekyll.lua` through `quarto pandoc` under `中`. Three older setup tests were removed as weaker repeats. The crash trace is `cairn/references/deno-script-crash.md`: 18 macOS crash reports with one stack (a call through a null function pointer in a `tokio-runtime-worker` thread, 39 to 100 ms after start), matching quarto-cli#10426 and denoland/deno#37045, a SQLite start-up race in Deno 2.7.14 on arm64. Nothing was posted upstream, at the user's choice. NEWS gives the switch for sites made earlier; D-023 supersedes D-004's TypeScript wording.

**Decisions:** none milestone-local. The user chose the Lua move over a trace-only milestone (D-023), and the final AC3 wording after its second re-audit.
