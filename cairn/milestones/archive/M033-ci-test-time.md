# M033: Each CI job runs the tests once, in parallel

**Status:** done (2026-10-22, PR #32 https://github.com/jmgirard/supplement/pull/32)

**Goal:** Each R-CMD-check job takes at most 60% of its time on the PR #31 run, because the tests run once per job, test files run in parallel, and string-rule loops skip on Windows.

**Outcome:** The workflow's "List skipped tests" step runs `.github/scripts/check-skips.R`, which reads the skip section of R CMD check's `tests/testthat.Rout` (or `.Rout.fail`), joins wrapped lines, and fails on a missing file, a missing summary line, `PASS 0`, a count mismatch, or a skip whose reason holds a missing-tool text; the missing-tool list moved there. The two tests that read the package's R files moved to `tests/testthat/test-source.R`, which a last step runs from the checkout. DESCRIPTION sets `Config/testthat/parallel: true` and `start-first`; the workflow sets `TESTTHAT_CPUS` per runner (4, 3, 4).
