## Candidates

- release checks: `check_supplement()` finds files over 100 MB, tracked `.rds` files, reports with no freeze output, broken links, and mismatched DOIs. `release_supplement()` bumps the version and prints the tag and release commands. — added 2026-10-18 — started M008
- template install from GitHub: recommend a pinned tag (`@vX.Y.Z`) in the README once a release exists. Narrowed 2026-10-18: the untagged route ran after the M003 merge and rendered. From the M003 review. — added 2026-10-18
- Windows check: run the template tests and a render on Windows (CI or by hand), including the no-R test, which skips there, and `nojekyll.ts` with a `C:\` output path. From the M003 review. Also from the M004 review: data files of 2 GiB or more may read as missing (32-bit `ftell` in Windows Lua), and the 1 GB sparse size fixture may cost 1 GB of disk off macOS when Quarto copies it into `docs/`. Also from the M006 review: `create_supplement()` path handling on Windows (a broken link or junction at a template path, where `Sys.readlink()` returns `""`, and trailing separators). — added 2026-10-18
- license footer: the template footer in `_quarto.yml` names MIT and CC BY 4.0, while `_supplement.yml` holds `license.code` and `license.content`, which no page reads (`write_citation()` and `write_zenodo()` do, so a mismatch also reaches the citation files); drive the footer from `_supplement.yml` so the two cannot differ. From the M004 review; widened in the M005 review. — added 2026-10-18
- shortcode edge cases: from the M004 review. `file` values are read as Markdown, so read the raw value or encode it (names with `%`, `#`, `--`, `_x_` break). A `data` map instead of a list renders nothing, and bare strings give `not found: ''`. A path outside the project or an absolute path renders but is not published. A `{{< meta >}}` value that names an existing path is rewritten on subfolder pages, and a description written as `../data` shows as `data` there. A fresh site has an empty paragraph under "Archived Version". `quarto-required: ">=1.4.0"` is untested below 1.10. — added 2026-10-18
- metadata value checks: `write_citation()` and `write_zenodo()` write license ids as given, so `CC BY 4.0` gives an invalid CFF `license` and a Zenodo id that is not in its vocabulary. Check the SPDX shape, and that the lowercase id is in Zenodo's license vocabulary. From the M005 review. — added 2026-10-18
- badge DOI form: the `supplement-doi` shortcode writes a DOI as given, so `https://doi.org/10.5281/zenodo.1` in `_supplement.yml` breaks the badge, while `write_citation()` strips that prefix. Strip it, or stop the render, so the two agree. From the M005 review. The M008 review adds: `check_supplement()` strips the prefix on both sides, so it does not report that broken badge. — added 2026-10-18
- docs site and walkthrough: a package site built with the toolkit itself, plus a first-time guide to GitHub Pages and Zenodo. Its `_pkgdown.yml` reference index lists `write_citation()` and `write_zenodo()` (from the M005 review). — added 2026-10-18
- paper figure files: the model reports write the paper figures with ggsave to `analyses/*.pdf` and `analyses/*.png`, which `.gitignore` blocks, so the site does not publish them. Decide if the template gives figures a tracked, published folder. From the M001 review. — added 2026-10-18
- YAML insert edge shapes: from the M007 review. `#` lines inside a block scalar, and `|+` trailing blank lines, at the end of the last item make add_report() and add_data() refuse valid YAML. A menu that already lists `analyses/<name>.qmd` with the file gone gets a second item. A file with old Mac line endings (CR only) reads as one line, so its menu or list reads as missing. A block-scalar value at the very end of a file with no final line break gains a trailing line break after the insert. — added 2026-10-18
- Windows-safe names: from the M007 review. add_report() accepts names that Windows reserves, such as `con`, and add_data() accepts base names that end in `.`, which Windows strips. `is_link()` reads `Sys.readlink()`, which returns `""` for a junction, so a junction `data/` or `analyses/` is not refused (see "Windows check"). — added 2026-10-18
- web link check: `check_supplement()` tests only links inside `docs/`. Also request each web address on the site's pages, which needs a network and can fail when a site is down. From the M008 plan. — added 2026-10-18
- stale stored output: `check_supplement()` finds reports with code but no stored output in `_freeze/`. Also find stored output that is older than its report source, from the source hash in each `execute-results/html.json`. From the M008 plan. — added 2026-10-18
- link check false positives: from the M008 review. `check_supplement()` does not decode `&amp;` or `&#38;` in a link, so `R&D.csv` reads as broken. It reads `href` text in HTML comments, in `<code>` text, and in `data-href` attributes, and it does not trim spaces around a value. It skips pages in hidden folders of `docs/`, and a symlink in `docs/` to a file outside the repository passes. Each fix changes the link check's criterion, so plan it as a milestone. — added 2026-10-18
- stored output chunk shapes: from the M008 review. The `no-stored-output` check misses chunks written ```` ``` {r} ````, chunks inside a `>` blockquote, `{R}`, and reports with only inline `r` code, and a four-backtick block that shows ```` ```{r} ```` as text gives a false row. See also "stale stored output". — added 2026-10-18
- release check edge cases: from the M008 review. A file in Git LFS reads as its full size in the large-file check, a large or `.rds` file committed earlier and since deleted is not seen though a push still sends it, and a second Zenodo badge on the home page (for a related dataset) gives a `doi-mismatch` row. — added 2026-10-18
- [low] existing-site migration: a helper that converts a site with the old `src/` and `analyses/` layout to the freeze layout. Out of scope for version 1. — added 2026-10-18
