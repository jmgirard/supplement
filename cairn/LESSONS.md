# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-19 (M014, used M064): The testthat `summary` reporter lists at most 10 failures. Count failures from `as.data.frame(devtools::test(reporter = "silent"))`. `testthat::test_file(desc =)` skips tests that call `skip_on_cran()` unless `NOT_CRAN=true`. In R CMD check's `tests/testthat.Rout`, testthat 3.3.2 writes each skip as `• <reason> (<n>): <locations>`. It wraps with a 2-space indent and cuts at the reason's first line break (M033).
- 2026-10-19 (M016, used M064): `readLines()` on a connection opened with `encoding = "UTF-8"`, as `yaml::read_yaml()` opens one, stops at the first byte that is not UTF-8. It gives only a warning, and the caller parses cut text. To refuse such a file, read the bytes and test `validUTF8()`, as `read_text_lines()` does. cli reads a `{x}` value as plain text. Put a message that holds `{` or `}` in as a value, never in the template.
- 2026-10-19 (M017): In a render by name or a full render, Quarto 1.10 copies each `project.resources` file at the times DESIGN.md's `_quarto.yml` entry gives. A render by name never removes a file from `docs/`, but a full render does. After a format is dropped, a full render removes its output but keeps its `_freeze/.../execute-results/<format>.json` (M043). A render by name rewrites a format's `.json` that does not parse (M044).
- 2026-10-19 (M018, used M060): On Windows (R 4.6), `Sys.readlink()` gives `""` for a junction and for a symbolic link. `normalizePath()` resolves a junction, so compare with the parent's normalized path plus the name. A file link to a missing file reads as an existing file, and `file.info()` on it warns. `fs::is_link()` reads it, a junction, and a folder link as links (M045). `Sys.junction()` makes test junctions without admin rights.
- 2026-10-19 (M018): Lua `seek("end")` in Quarto's Pandoc gives -1 for a file of 2 GiB or more. Windows file names cannot hold `*`, `?`, or a line break. On Windows, `fsutil sparse setflag` and then `fsutil file seteof` make a sparse fixture.
- 2026-10-19 (M018, M030, M031): Quarto 1.10 looks for R in `QUARTO_R`, then `R_HOME/bin`, then `which Rscript`. An empty `QUARTO_R` folder leaves it no R. R CMD check puts stub `R` and `Rscript` scripts first on the PATH, and they exit 1. A test starts `file.path(R_HOME, "bin", "Rscript")`. Under `--as-cran`, `R_LIBS` holds only declared packages, but `.Library` stays visible. Only a failing test makes R CMD check print test output.
- 2026-10-19 (M019): `system2()` runs `shQuote(command)` itself. A command path passed through `shQuote()` is quoted twice and fails with "error in running command". Pass the path bare and quote only the arguments. When a Lua project script fails, Quarto 1.10.19 exits 1 and prints Pandoc's error (corrected M048). The R-CMD-check workflow has no path filter, so a tracking-only push to an open PR reruns all six jobs (corrected M033).
- 2026-10-20 (M021, used M064): PCRE's match limit in R (`perl = TRUE`) counts the steps of one match. A lazy `[\s\S]*?` over a 5 MB body makes `gsub()` warn "match limit exceeded" and return its input unchanged. Catch the warning, and use possessive repeats with a one-class body (`[^<]*+`). With `useBytes = TRUE`, `(?i)` and `toupper()` follow the locale (Turkish `i`). Spell ASCII names as `[Ss][Cc]…` and lower them with `chartr()`.
- 2026-10-20 (M022, used M063): `sort()` and `order()` with `method = "radix"` stop with "Character encoding must be UTF-8, Latin-1 or bytes" on a string with no encoding mark that is not valid UTF-8, which is what `list.files()` returns for such a name; set `Encoding(keys) <- "bytes"` on a copy and order by it.
- 2026-10-20 (M022): On the GitHub Windows runner (R 4.6), `unlink()` cannot remove a folder symbolic link ("cannot delete reparse point") and warns in test cleanup. Tests make folder links there with `Sys.junction()`. `file.create()` stops ("file name conversion problem") on a name that is not valid UTF-8, where macOS returns FALSE. Wrap it in `tryCatch()` before a skip.
- 2026-10-20 (M023): A `skip_on_os()` placed after a test's expectations keeps them and records the skip with its reason. One test can run the cases that every system supports and then skip the rest.
- 2026-10-20 (M024): Quarto 1.10 picks a report's engine from a scan of the raw text, and knitr 1.52 runs a chunk inside a four-backtick example block or an HTML comment. A report with only inline `` `r x` `` code runs nothing unless its front matter sets `engine: knitr`, and knitr also runs `` `r# x` ``. To learn what a render runs, render a probe file and look for `_freeze/<path>/execute-results/`.
- 2026-10-20 (M025): A Windows path in a double-quoted YAML string reads `\` as an escape (`\U` needs eight hex digits, `\t` is a tab), so a test that writes a temp path into YAML builds it with `normalizePath(winslash = "/")`. A quote in that path also breaks the value, and a read site that catches parse errors (`tryCatch()` to NULL) then passes the test without reaching the code under test.
- 2026-10-20 (M026, used M059): `readLines(warn = FALSE)` cuts a line at an embedded nul with no warning, and `rawToChar()` stops at 2^31 bytes. Read text that can hold a nul with `readBin()`. Unless front matter names an engine, Quarto 1.10 starts knitr for `r` and julia for `julia`. It starts Jupyter for every other chunk name but `ojs`, `mermaid`, and `dot`. knitr 1.52 writes an unknown engine's code out unrun.
- 2026-10-21 (M027, used M062): Quarto 1.10.19 writes the `hash` of each `_freeze/<path>/execute-results/<format>.json` as the MD5 of the report read as UTF-8, with CR LF turned into LF. A bad byte becomes U+FFFD, and a BOM and a lone CR stay. The hash covers the report file alone, not its includes, `_quarto.yml`, or `_metadata.yml`. `tools::md5sum()` with no `tools` in Imports gave no R CMD check note (R 4.6).
- 2026-10-21 (M028, used M058): Quarto 1.10.19 sets `QUARTO_PROJECT_DIR` for every render, from a subfolder too. Its `figures/**` glob copies hidden files. The quartz `png()` device writes its file only at `dev.off()`. Windows-only tests hold hand-written lists of template folders, so grep for them before you add one. A test can read a printed value back from the `<pre><code>[1] 10</code></pre>` of the `cell-output-stdout` div in `docs/` (M034).
- 2026-10-21 (M029): `git ls-files --others --ignored --exclude-standard` lists each file in an ignored folder, a link as one entry, and an ignored nested repository as one `dir/` entry. On macOS `git init` sets `core.precomposeunicode=true`. git then lists a decomposed name in composed form, while `list.files()` gives the stored bytes. Read git's own lists, and do not compare them with a disk walk.
- 2026-10-22 (M031, M032): `renv::init()` in a test writes to the user's renv cache and sandbox unless `RENV_PATHS_ROOT` and `RENV_PATHS_SANDBOX` name temporary folders. An inherited `RENV_PATHS_*` or `RENV_PROFILE` moves its writes again. Set `RENV_SANDBOX_LOCKING_ENABLED=FALSE` so withr can delete the sandbox. In a cloned renv project, run other tools with `Rscript --no-init-file`. Ask `renv::paths$library()` for the library path.
- 2026-10-26 (M058, used M061): `source(file)` with the default `local = FALSE` defines the file's functions in the global environment. Chunk code that a test runs with `eval(envir = env)` then gives them no `site` to find, so the `site` chunk sources `_scripts/report.R` with `local = TRUE`. A knitr render runs chunks in the global environment and is the same. Quarto 1.10 copies no `_`-named folder, such as `_scripts/`, into `docs/`.
- 2026-10-26 (M059, used M064): One PCRE pattern with `.*` between two names, such as `_scripts.*report\.R`, passes R's match limit on a line of 3 to 5 MB, so `grepl()` warns and returns FALSE. A possessive repeat cannot help, since the match must backtrack. Find each name with its own `regexpr()` or `gregexpr()` and compare their positions, or match only the text that can lie between them, as `names_script()` does (corrected M060).
- 2026-10-26 (M060): In fs 2.1.0, `fs::is_file()` and `fs::file_info(follow = TRUE)` never return on a link to a link, because their loop reads the first link again. `fs::path_real()` resolves the chain, and on macOS it signals class `ENOENT` for a missing target and `ELOOP` for a loop. On the windows-latest runner `file.symlink()` makes file links, and `fs::path_real()` fails on a file link to a missing file.
- 2026-10-26 (M061): A function in `_scripts/report.R` that reads `site` when it runs sees the report's later value, and a report can reuse `site` for its own data (`site <- "Boston"`). Take what the function needs when the `site` chunk sources the file, in a `local()` closure, as `print_environment()` does for its MD5. A test of a report.R function also changes `site` after the source.
- 2026-10-26 (M061, used M064): `paste0("prefix", character())` returns `"prefix"`, not `character(0)`, since `recycle0` is FALSE by default. A fixture helper that builds lines with `paste0()` from an empty vector writes the prefix alone, so a "no such line" case holds the line. Guard the empty case, and plant the defect to see the case go red.
- 2026-10-27 (M063, used M064): To mock base `curlGetHeaders()` with `local_mocked_bindings()`, bind `curlGetHeaders <- NULL` in the package; a call skips the NULL and finds base. On macOS it gave libcurl error 92 (HTTP/2 stream) for a missing page, not 404, and libcurl rejects a raw space in an address. A test helper that makes a site passes its caller's env to `new_site()`, or the site is deleted when the helper returns.
- 2026-10-27 (M064): `jsonlite::parse_json()` reads text with no encoding mark in the native encoding, so in a Latin-1 locale it misreads UTF-8 such as `─`. Set `Encoding(x) <- "UTF-8"` first. It warns on a UTF-8 BOM. sessioninfo 1.2 prints its rules as `- Packages` when cli output is not UTF-8, adds the `!` column only when a package has a problem, and with colors on puts ANSI codes in the rule and header.
