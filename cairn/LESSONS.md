# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-19 (M014, used M067): The testthat `summary` reporter lists at most 10 failures. Count failures from `as.data.frame(devtools::test(reporter = "silent"))`. `testthat::test_file(desc =)` skips tests that call `skip_on_cran()` unless `NOT_CRAN=true`. In R CMD check's `tests/testthat.Rout`, testthat 3.3.2 writes each skip as `• <reason> (<n>): <locations>`. It wraps with a 2-space indent and cuts at the reason's first line break (M033).
- 2026-10-19 (M016, used M068): `readLines()` on a connection opened with `encoding = "UTF-8"`, as `yaml::read_yaml()` opens one, stops at the first byte that is not UTF-8. It gives only a warning, and the caller parses cut text. To refuse such a file, read the bytes and test `validUTF8()`, as `read_text_lines()` does. cli reads a `{x}` value as plain text. Put a message that holds `{` or `}` in as a value, never in the template.
- 2026-10-19 (M018, used M068): On Windows (R 4.6), `Sys.readlink()` gives `""` for a junction and for a symbolic link. `normalizePath()` resolves a junction, so compare with the parent's normalized path plus the name. A file link to a missing file reads as an existing file, and `file.info()` on it warns. `fs::is_link()` reads it, a junction, and a folder link as links (M045). `Sys.junction()` makes test junctions without admin rights.
- 2026-10-19 (M018, M030, M031, used M072): Quarto 1.10 looks for R in `QUARTO_R`, then `R_HOME/bin`, then `which Rscript`. An empty `QUARTO_R` folder leaves it no R. R CMD check puts stub `R` and `Rscript` scripts first on the PATH, and they exit 1. A test starts `file.path(R_HOME, "bin", "Rscript")`. Under `--as-cran`, `R_LIBS` holds only declared packages, but `.Library` stays visible. Only a failing test makes R CMD check print test output.
- 2026-10-20 (M021, used M064): PCRE's match limit in R (`perl = TRUE`) counts the steps of one match. A lazy `[\s\S]*?` over a 5 MB body makes `gsub()` warn "match limit exceeded" and return its input unchanged. Catch the warning, and use possessive repeats with a one-class body (`[^<]*+`). With `useBytes = TRUE`, `(?i)` and `toupper()` follow the locale (Turkish `i`). Spell ASCII names as `[Ss][Cc]…` and lower them with `chartr()`.
- 2026-10-20 (M022, used M063): `sort()` and `order()` with `method = "radix"` stop with "Character encoding must be UTF-8, Latin-1 or bytes" on a string with no encoding mark that is not valid UTF-8, which is what `list.files()` returns for such a name; set `Encoding(keys) <- "bytes"` on a copy and order by it.
- 2026-10-20 (M026, used M070): `readLines(warn = FALSE)` cuts a line at an embedded nul with no warning, and `rawToChar()` stops at 2^31 bytes. Read text that can hold a nul with `readBin()`. Unless front matter names an engine, Quarto 1.10 starts knitr for `r` and julia for `julia`. It starts Jupyter for every other chunk name but `ojs`, `mermaid`, and `dot`. knitr 1.52 writes an unknown engine's code out unrun.
- 2026-10-21 (M027, used M071): Quarto 1.10.19 writes the `hash` of each `_freeze/<path>/execute-results/<format>.json` as the MD5 of the report read as UTF-8, with CR LF turned into LF. A bad byte becomes U+FFFD, and a BOM and a lone CR stay. The hash covers the report file alone, not its includes, `_quarto.yml`, or `_metadata.yml`. `tools::md5sum()` with no `tools` in Imports gave no R CMD check note (R 4.6).
- 2026-10-21 (M028, used M072): Quarto 1.10.19 sets `QUARTO_PROJECT_DIR` for every render, from a subfolder too. Its `figures/**` glob copies hidden files. The quartz `png()` device writes its file only at `dev.off()`. Windows-only tests hold hand-written lists of template folders, so grep for them before you add one. A test can read a printed value back from the `<pre><code>[1] 10</code></pre>` of the `cell-output-stdout` div in `docs/` (M034).
- 2026-10-21 (M029, used M068): `git ls-files --others --ignored --exclude-standard` lists each file in an ignored folder, a link as one entry, and an ignored nested repository as one `dir/` entry. On macOS `git init` sets `core.precomposeunicode=true`. git then lists a decomposed name in composed form, while `list.files()` gives the stored bytes. Read git's own lists, and do not compare them with a disk walk.
- 2026-10-22 (M031, M032, used M067): `renv::init()` in a test writes to the user's renv cache and sandbox unless `RENV_PATHS_ROOT` and `RENV_PATHS_SANDBOX` name temporary folders. An inherited `RENV_PATHS_*` or `RENV_PROFILE` moves its writes again. Set `RENV_SANDBOX_LOCKING_ENABLED=FALSE` so withr can delete the sandbox. In a cloned renv project, run other tools with `Rscript --no-init-file`. Ask `renv::paths$library()` for the library path.
- 2026-10-26 (M059, used M064): One PCRE pattern with `.*` between two names, such as `_scripts.*report\.R`, passes R's match limit on a line of 3 to 5 MB, so `grepl()` warns and returns FALSE. A possessive repeat cannot help, since the match must backtrack. Find each name with its own `regexpr()` or `gregexpr()` and compare their positions, or match only the text that can lie between them, as `names_script()` does (corrected M060).
- 2026-10-26 (M061): A function in `_scripts/report.R` that reads `site` when it runs sees the report's later value, and a report can reuse `site` for its own data (`site <- "Boston"`). Take what the function needs when the `site` chunk sources the file, in a `local()` closure, as `print_environment()` does for its MD5. A test of a report.R function also changes `site` after the source.
- 2026-10-26 (M061, used M072): `paste0("prefix", character())` returns `"prefix"`, not `character(0)`, since `recycle0` is FALSE by default. A fixture helper that builds lines with `paste0()` from an empty vector writes the prefix alone, so a "no such line" case holds the line. Guard the empty case, and plant the defect to see the case go red.
- 2026-10-27 (M063, used M064): To mock base `curlGetHeaders()` with `local_mocked_bindings()`, bind `curlGetHeaders <- NULL` in the package; a call skips the NULL and finds base. On macOS it gave libcurl error 92 (HTTP/2 stream) for a missing page, not 404, and libcurl rejects a raw space in an address. A test helper that makes a site passes its caller's env to `new_site()`, or the site is deleted when the helper returns.
- 2026-10-27 (M064, used M068): `jsonlite::parse_json()` reads text with no encoding mark in the native encoding, so in a Latin-1 locale it misreads UTF-8 such as `─`. Set `Encoding(x) <- "UTF-8"` first. sessioninfo 1.2 prints its rules as `- Packages` when cli output is not UTF-8, adds the `!` column only when a package has a problem, and with colors on puts ANSI codes in the rule and header.
- 2026-10-27 (M065, used M073): sessioninfo 1.2.4 `session_info()` lists no base package, even one that is attached, and marks an attached package with `*` under the `*` of its header. A Quarto 1.10 knitr render of the template example attaches no package: knitr and rmarkdown are only loaded. `gh pr checks --watch --fail-fast` exited 1 with every check passed and one skipped, so read the check states, not the exit code.
- 2026-10-27 (M066, used M068): Windows file names cannot hold `*`, `?`, a line break, or a trailing space, which a folder name loses. There `file.exists()` stops with "file name conversion problem" on a path whose bytes are not UTF-8, and macOS refuses to make such a name. cli stops with "input string 1 is invalid UTF-8" on such text, so pass it through `show_text()`. `withr::local_envvar()` at a test file's top level holds for that file only.
- 2026-10-27 (M067, used M068): With `RENV_PATHS_LIBRARY` set and a profile active, renv 1.3.1 puts the library at `<RENV_PATHS_LIBRARY>/profiles/<name>/renv` and reads `renv/profiles/<name>/renv.lock` under the project, so an image sets `RENV_PROFILE` for the build and the render. renv reads `renv/profile` with `readLines()`, which ends a line at CR too and, in a UTF-8 locale only, drops a UTF-8 byte order mark.
- 2026-10-28 (M068, used M073): `R-CMD-check.yaml` and `pkgdown.yaml` have no path filter, so each push to a PR branch, a commit of `cairn/` files only included, reruns all 9 checks. On 2026-10-28 windows-latest took 10.7 and 11.1 minutes, past the 10-minute limit of one foreground `gh pr checks --watch`. Push tracking commits before the CI wait, or leave them unpushed until the merge.
- 2026-10-28 (M069, used M070): `pkgdown.yaml` runs on pull requests and pushes to main, so a branch push builds no site. `gh workflow run pkgdown.yaml --ref <branch>` builds one (the deploy job is skipped off main), and `gh run download <id> -n site` fetches it, kept 1 day. pkgdown 2.2 writes a relative navbar `href` with `../` on pages one folder down, and keeps the default right-side items when `_pkgdown.yml` sets only `left`.
- 2026-10-28 (M070): On macOS (R 4.6), Rscript writes each space in a script's path as `~+~` in its `--file=` argument, so a script that finds its own folder through `commandArgs()` turns `~+~` back into a space. After an error stops Rscript, R still deletes the session's `tempdir()`, so `tempfile()` folders need no cleanup on a failure path. `gregexpr(fixed = TRUE)` counts overlapping copies as one.
- 2026-10-28 (M071): Quarto 1.10.19's default listing sort puts items with a numeric `order` first, lowest first, ties by title, then the rest by title; a quoted `order` stops the render. R's yaml package reads YAML 1.1: `010` is 8, `1e3` and `1_000` are text, and 3000000000 is NA. `paste0(c(x, ""), lines)` recycles `x` onto every other line, so prefix only `lines[1]`.
- 2026-10-28 (M072): `system2()` quotes the program path with `shQuote()` itself, so a path quoted first is not found (status 127). With the default `stdout = ""` its output goes to the console, not to R, so `capture.output()` and testthat cannot read it; a test that needs Quarto's text uses `run_in()`. `file.exists()` ignores case on macOS and Windows, so match a name against `list.files()` to keep its case.
- 2026-10-28 (M073): usethis 3.2.2 `use_github()` names the repository after the folder. For about a minute after it pushes, GitHub's API can report another default branch, so `git_default_branch()` stops with "Default branch mismatch"; wait and run again. usethis asks yes/no through `utils::menu()`, so a scripted walk sets `options(rlang_interactive = TRUE)` and replaces `menu` in the utils namespace.
