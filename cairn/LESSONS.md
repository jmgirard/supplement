# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-18 (M001): `quarto render <file>` ignores `freeze: true` and runs that file's code, and it writes that file's stored output to `_freeze/` (checked M008). Only a full project render reuses `_freeze/`. gt writes random table ids, so each re-render shows a diff with no change in results.
- 2026-10-18 (M002): Matching printed numbers do not prove a re-render reproduces a report. Unseeded random draws, such as `pp_check(ndraws = 100)`, redraw figures each time, and the Bootstrap theme file name differs between machines. Compare figure hashes as well as numbers.
- 2026-10-18 (M003): `quarto use template` skips dotfiles, README.md, and LICENSE, and in a git repository Quarto writes its own `.gitignore` before pre-render scripts run. Template setup must merge into an existing `.gitignore`, not replace or skip it.
- 2026-10-18 (M003): git ignore rules are case-sensitive on Linux, so match file extensions with bracket patterns such as `*.[Rr][Dd][Ss]`. A trailing `!docs/` undoes an earlier `docs/` rule but not `docs/*`.
- 2026-10-18 (M004): In Quarto 1.10 Lua filters and shortcodes, the global `error()` only prints a message and returns, so stop a render with `assert(false, msg)`. Quarto also rewrites any metadata string that names an existing path to be relative to the page, and parses metadata strings as Markdown, so file names with `--` or `_x_` change before Lua sees them.
- 2026-10-18 (M005): R's yaml package reads YAML 1.1: unquoted `No` is FALSE, `1.10` is 1.1, `0755` is 493, `.na` is a logical NA, and a sequence of scalars, `[x]` included, becomes a plain vector. Pass `handlers = list(seq = function(x) as.list(x))` to keep sequences as lists (`yaml_load_list()` does, with `eval.expr = FALSE`; corrected M025), and check `is.character()` before using a value as text. `yaml::as.yaml()` double-quotes a string that carries the attribute `quoted = TRUE`.
- 2026-10-18 (M006): `file.copy()` from an unreadable source creates an empty target and returns FALSE, so cleanup code must record the target before the copy. On macOS `file.exists("file/")` is FALSE for an existing file, so drop trailing separators before checks. `list.files(recursive = TRUE)` without `all.files` skips hidden files and the contents of hidden folders. `Sys.readlink()` returns NA for a path that does not exist, and `nzchar(NA)` is TRUE, so test `!is.na(link) && nzchar(link)` to find a link (M005).
- 2026-10-18 (M007): cli drops the spaces at the start of each message line, so an error that shows YAML to add by hand needs a base R condition with a `cli::format_message()` header. R only warns when a write fills the disk ("Problem closing connection"), so a write check must catch warnings or compare the file size.
- 2026-10-18 (M008): `regmatches()` and `sub()` with `useBytes = TRUE` return strings marked "bytes", and `file.path()` and `sprintf()` then stop with an unclassed error, so read text as UTF-8 (repair bad bytes with `iconv(x, "UTF-8", "UTF-8", sub = "byte")`) and match without `useBytes`, or set `Encoding(x) <- "UTF-8"` on the results. Over a long string with a non-ASCII character, `gregexpr()` without `useBytes` takes time that grows with the square of the match count, so match a whole page as bytes and mark the results UTF-8 again (corrected M021). `Sys.glob()` over a full path reads `[`, `*`, and `?` in folder names as patterns, so list the folder instead. On macOS `file.exists()` ignores letter case, while GitHub Pages does not.
- 2026-10-18 (M008): `yaml::read_yaml()` warns on a valid file with no final line break, so a `tryCatch()` that treats warnings as failure rejects good files; parse the text with `yaml.load()` inside `suppressWarnings()`. A block-scalar value keeps its final line break only when a key follows it.
- 2026-10-18 (M009): A criterion that quantifies over an open domain ("any other value", "for any reason", "each file it made"), or that names literal test strings the test then varies, gives each fresh review reader a new failing reading, and M009 took four returns that way. Write each criterion as a stated rule plus a listed set of tests, name input shapes rather than literal strings, and have review floor a return only when a listed test or a stated rule fails.
- 2026-10-18 (M009): `unlink()` expands `[`, `*`, and `?` in its path by default, so `unlink("site[ab]/f")` removes `sitea/f` and leaves `site[ab]/f`. Remove a known path with `file.remove()` or `unlink(expand = FALSE)`. `as.vector(unclass(x))` keeps an S4 object's S4 bit; `as.character(x)` drops it.
- 2026-10-18 (M010): Quarto 1.10 runs shortcodes, both `{{< meta >}}` and extension shortcodes, inside `website.page-footer` on every page, subfolder pages included, so a footer can read `_supplement.yml`. To prove a template test can fail, copy the file from main over the working file (`git show main:<path> > <path>`), run the test, then restore it from a scratch copy.
- 2026-10-18 (M011): To test what a function does when a file changes during a slow step, mock that step (`local_mocked_bindings()`) to edit the folder and save `folder_state()` inside the mock, then compare after the call. A test edit meant to change one line writes bytes with `writeBin()`, because `writeLines()` writes CRLF on Windows and changes every line.
- 2026-10-18 (M012): In testthat 3e, `expect_error(class =)` also passes when only a parent error has the class, so a test that an error is not wrapped must check `inherits()` on the returned error itself. A helper argument such as `state = folder_state(dir)` is a lazy promise, so it is read when the helper first uses it, which can be after the call under test; read it into a variable before the call. `yaml::yaml.load()` takes `error.label`, which `read_yaml()` uses to name the file in a parser error.
- 2026-10-19 (M013): testthat 3.2.0 to 3.2.3 do not compile under R 4.6 (`reassign.c` calls `SET_FORMALS`, `BODY`, `CLOENV`); 3.3.0 does. devtools 2.5.2 needs testthat 3.3.2, so run the suite under an older testthat with `testthat::test_local()` and the old release's library first in `.libPaths()`, and print `packageVersion("testthat")` in the run. `getParseData()` ids do not follow text order, so compare `line1` and `col1` to find the left side of an assignment.
- 2026-10-19 (M014): In a Quarto 1.10 shortcode, a metadata value arrives as: one `Str` for a plain word, several inline elements for text with spaces or Markdown, the Lua string `""` for a YAML null, Blocks holding one Para for a block or folded string, a `List` for a list, a plain table for a map, a boolean for `true`, and one `Str` for an unquoted number (`1.0` becomes `1`). `pandoc.utils.stringify()` joins paragraphs with no space. Named shortcode arguments go to `kwargs`, so a count of `args` misses them.
- 2026-10-19 (M014): The testthat `summary` reporter lists at most 10 failures, so count failures from `as.data.frame(devtools::test(reporter = "silent"))`. `testthat::test_file(desc =)` skips tests that call `skip_on_cran()` unless `NOT_CRAN=true` is set.
- 2026-10-19 (M015): `git commit -m msg -- .` commits only paths under the current folder and leaves files staged elsewhere staged; git refuses it during a merge, cherry-pick, or revert. `git diff-tree --name-only -r HEAD` lists nothing for a first commit without `--root`. git before 2.32 ignores `GIT_CONFIG_GLOBAL`, so a test that commits sets `commit.gpgsign false` and `core.hooksPath` in its own repository.
- 2026-10-18 (M007): With `perl = TRUE`, `$` also matches before a final `\n`, so anchor names with `\z`. PCRE needs `(*UCP)` for `\S` to skip Unicode spaces, and `\x{2028}` in a pattern fails on an ASCII-only string. A valid UTF-8 string marked "bytes" is not `identical()` to the same text read by the yaml package.
- 2026-10-19 (M016): `readLines()` on a connection opened with `encoding = "UTF-8"` (as `yaml::read_yaml()` opens one) stops at the first byte that is not UTF-8, with only a warning, so the caller parses cut text; read the bytes and test `validUTF8()`, as `read_text_lines()` does, to refuse such a file. cli reads a `{x}` value as plain text, so a message that holds `{` or `}`, such as a yaml parser message, goes in as a value and never in the template.
- 2026-10-19 (M017): Quarto 1.10 lists the files a `project.resources` glob matches at the start of a render and copies them after the report code runs, so a file a report writes under a new name reaches `docs/` only on the next render (by name or full), while new bytes under an existing name are copied in the same render. A render by name never removes a file from `docs/`; a full render does.
- 2026-10-19 (M018): On Windows (R 4.6), `Sys.readlink()` gives `""` for a junction and for a symbolic link. A junction shows under `normalizePath()`, which resolves it, so compare with the parent's normalized path plus the name, after dropping a drive root's trailing `/`. A file link to a missing file reads as an existing file (`file.exists()` TRUE, `file.access()` 0, `normalizePath()` its own path), and `file.info()` on it warns. `Sys.junction()` makes test junctions without admin rights.
- 2026-10-19 (M018): On the GitHub Windows runner, the checkout writes CRLF unless `.gitattributes` sets `eol=lf`. The temporary folder holds the 8.3 short name `RUNNER~1`, and Quarto run from such a folder does not find knitr's figures, so tests run it from `normalizePath()` of the folder. Lua `seek("end")` in Quarto's Pandoc gives -1 for a file of 2 GiB or more. Windows file names cannot hold `*`, `?`, or a line break. `fsutil sparse setflag` then `fsutil file seteof` make a sparse fixture.
- 2026-10-19 (M018): Quarto 1.10 reads `QUARTO_R` before R_HOME, PATH, and the Windows registry. An existing empty folder there leaves it no R ("Unable to locate an installed version of R") on every system. testthat 3.3.2's `skip_if_not_installed()` reason is "{pkg} is not installed". `R CMD check` prints test output only when a test fails. Quarto copies each local file a page links into `docs/`, not only `project.resources` files; on macOS a sparse file stays sparse.
- 2026-10-19 (M019): `system2()` runs `shQuote(command)` itself, so a command path passed through `shQuote()` is quoted twice and fails with "error in running command"; pass the path bare and quote only the arguments. When a project script such as `_scripts/setup.ts` fails, Quarto 1.10.19 throws an `Error` with no message, so the render exits 1 after printing only "Running script '<script>'"; set `QUARTO_LOG_LEVEL=DEBUG` to see the script's exit code in the `[execProcess] Success: …, code: …` line. That level adds about 300 lines to a good render's stderr, and `[execProcess]` lines also appear for Quarto's own `git rev-parse` (code 128 outside a repository), so match the exact line (M020). The R-CMD-check workflow has no path filter, so a push of tracking-only commits to an open PR restarts all six jobs; the Windows jobs take about 30 minutes (M020, M030).
- 2026-10-21 (M030): R CMD check puts stub `R` and `Rscript` scripts first on the PATH, which exit 1 ("should not be used without a path"), so a test starts `file.path(R_HOME, "bin", "Rscript")`; Quarto 1.10 with `QUARTO_R` unset also uses that one before the PATH. Under `--as-cran` the tests get `R_LIBS` with links to declared packages only, but a package in `.Library` (sessioninfo can sit there on macOS) stays visible. On the Windows runner, `R_PROFILE_USER` set for a `quarto render` did not reach the R that Quarto ran, while an `include: false` chunk in the report works everywhere. A logical `info =` makes a failing testthat expectation stop with "`info` must be a character vector", which hides the failure. `sessioninfo::session_info()` runs `quarto -V`, which prints a mkdir error under an unwritable HOME.
- 2026-10-20 (M021): PCRE's match limit in R (`perl = TRUE`) counts the steps of one match, including each repeat of a group, so a lazy `[\s\S]*?` over a 5 MB body, or a possessive group repeated for each of 5 million `<`, makes `gsub()` warn "match limit exceeded" and return its input unchanged; catch the warning, and use possessive `*+` repeats with a single-class body (`[^<]*+`) to keep time linear. With `useBytes = TRUE`, `(?i)` uses the locale's byte case tables, and `toupper()`/`tolower()` follow the locale (Turkish `i`), so spell ASCII names as `[Ss][Cc]…` and lower them with `chartr()`.
- 2026-10-20 (M022): `sort()` and `order()` with `method = "radix"` stop with "Character encoding must be UTF-8, Latin-1 or bytes" on a string with no encoding mark that is not valid UTF-8, which is what `list.files()` returns for such a name; set `Encoding(keys) <- "bytes"` on a copy and order by it.
- 2026-10-20 (M022): On the GitHub Windows runner (R 4.6), `file.symlink()` works, but `unlink()` cannot remove a folder symbolic link ("cannot delete reparse point … mismatch between the tag") and warns in test cleanup, so tests make folder links with `Sys.junction()` there. `file.create()` stops with an error ("file name conversion problem") on a name that is not valid UTF-8, where macOS returns FALSE, so wrap it in `tryCatch()` before a skip.
- 2026-10-20 (M023): Microsoft's reserved device names are `CON`, `PRN`, `AUX`, `NUL`, `COM1` to `COM9`, and `LPT1` to `LPT9` (plus superscript-digit forms), with any extension; `COM0` and `LPT0` are not on the list. A `skip_on_os()` placed after a test's expectations keeps them and records the skip with its reason, so one test can run the cases every system supports and then skip the rest.
- 2026-10-20 (M024): Quarto 1.10 picks a report's engine from a scan of the raw text, and knitr 1.52 runs a chunk inside a four-backtick example block or an HTML comment. A report with only inline `` `r x` `` code runs nothing unless its front matter sets `engine: knitr`, and knitr also runs `` `r# x` ``. To learn what a render runs, render a probe file and look for `_freeze/<path>/execute-results/`.
- 2026-10-20 (M024): `yaml::yaml.load()` runs `!expr` values when the user sets `options(yaml.eval.expr = TRUE)`, so pass `eval.expr = FALSE` to read a file without running its code. A test sets the option with `withr::local_options()` and checks that a marker file the `!expr` would make does not exist.
- 2026-10-20 (M025): A Windows path in a double-quoted YAML string reads `\` as an escape (`\U` needs eight hex digits, `\t` is a tab), so a test that writes a temp path into YAML builds it with `normalizePath(winslash = "/")`. A quote in that path also breaks the value, and a read site that catches parse errors (`tryCatch()` to NULL) then passes the test without reaching the code under test.
- 2026-10-20 (M026): `readLines(warn = FALSE)` gives no warning on an embedded nul and cuts that line at the nul, and `rawToChar()` stops with "long vectors not supported yet" at 2^31 bytes, so read text that may hold a nul with `readBin()`, map the nul to another byte, and keep the whole read in one `tryCatch()`. Unless front matter names an engine, Quarto 1.10 starts knitr for `r`, julia for `julia`, and Jupyter for every other chunk name but `ojs`, `mermaid`, and `dot`; it refuses a nul in front matter ("null byte is not allowed"). knitr 1.52 knows `bash`, `sql`, and `Rcpp`, and writes an unknown engine's code out unrun.
- 2026-10-21 (M027): Quarto 1.10.19 writes the top-level `hash` of each `_freeze/<path>/execute-results/<format>.json` as the MD5 of the report read as UTF-8 (each bad byte becomes U+FFFD, a BOM and a lone CR stay) with CR LF turned into LF. The hash covers the report file alone, not its includes, `_quarto.yml`, or `_metadata.yml`, and a render keeps the `.json` of a format the report no longer renders. `tools::md5sum()` in package code with no `tools` in Imports gave no R CMD check note or warning (R 4.6).
- 2026-10-21 (M028): Quarto 1.10.19 sets `QUARTO_PROJECT_DIR` to the project folder for a full render, a render by name, and a render run from a subfolder, and its `figures/**` resource glob copies hidden files too. On macOS the quartz `png()` device writes its file only at `dev.off()`. Tests that skip off Windows (`skip_on_os(c("mac", "linux", "solaris"))`) hold hand-written lists of template folders, so a new template folder fails only in the Windows CI job; grep for them before adding one.
- 2026-10-21 (M029): `git ls-files --others --ignored --exclude-standard` lists each file inside an ignored folder, a link as one entry that it never enters, and an ignored nested repository as one `dir/` entry. `git init` on macOS sets `core.precomposeunicode=true`, and git then lists a name stored in decomposed Unicode in composed form while `list.files()` gives the stored bytes, so read git's own lists rather than comparing git with a disk walk. `strsplit()` warns on a name that is not valid UTF-8 without `useBytes`, and on Windows `drop_trailing_sep()`'s `sub()` stops on one.
