# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-19 (M018, used M077): On Windows (R 4.6), `Sys.readlink()` gives `""` for a junction and for a symbolic link. `normalizePath()` resolves a junction, so compare with the parent's normalized path plus the name. A file link to a missing file reads as an existing file, and `file.info()` on it warns. `fs::is_link()` reads it, a junction, and a folder link as links (M045). `Sys.junction()` makes test junctions without admin rights.
- 2026-10-19 (M018, M030, M031, used M072): Quarto 1.10 looks for R in `QUARTO_R`, then `R_HOME/bin`, then `which Rscript`. An empty `QUARTO_R` folder leaves it no R. R CMD check puts stub `R` and `Rscript` scripts first on the PATH, and they exit 1. A test starts `file.path(R_HOME, "bin", "Rscript")`. Under `--as-cran`, `R_LIBS` holds only declared packages, but `.Library` stays visible. Only a failing test makes R CMD check print test output.
- 2026-10-20 (M021, used M076): PCRE's match limit in R (`perl = TRUE`) counts the steps of one match. A lazy `[\s\S]*?` over a 5 MB body makes `gsub()` warn "match limit exceeded" and return its input unchanged. Catch the warning, and use possessive repeats with a one-class body (`[^<]*+`). With `useBytes = TRUE`, `(?i)` and `toupper()` follow the locale (Turkish `i`). Spell ASCII names as `[Ss][Cc]…` and lower them with `chartr()`.
- 2026-10-21 (M027, used M071): Quarto 1.10.19 writes the `hash` of each `_freeze/<path>/execute-results/<format>.json` as the MD5 of the report read as UTF-8, with CR LF turned into LF. A bad byte becomes U+FFFD, and a BOM and a lone CR stay. The hash covers the report file alone, not its includes, `_quarto.yml`, or `_metadata.yml`. `tools::md5sum()` with no `tools` in Imports gave no R CMD check note (R 4.6).
- 2026-10-21 (M028, used M072): Quarto 1.10.19 sets `QUARTO_PROJECT_DIR` for every render, from a subfolder too. Its `figures/**` glob copies hidden files. The quartz `png()` device writes its file only at `dev.off()`. Windows-only tests hold hand-written lists of template folders, so grep for them before you add one. A test can read a printed value back from the `<pre><code>[1] 10</code></pre>` of the `cell-output-stdout` div in `docs/` (M034).
- 2026-10-26 (M059, used M076): One PCRE pattern with `.*` between two names, such as `_scripts.*report\.R`, passes R's match limit on a line of 3 to 5 MB, so `grepl()` warns and returns FALSE. A possessive repeat cannot help, since the match must backtrack. Find each name with its own `regexpr()` or `gregexpr()` and compare their positions, or match only the text that can lie between them, as `names_script()` does (corrected M060).
- 2026-10-26 (M061, used M072): `paste0("prefix", character())` returns `"prefix"`, not `character(0)`, since `recycle0` is FALSE by default. A fixture helper that builds lines with `paste0()` from an empty vector writes the prefix alone, so a "no such line" case holds the line. Guard the empty case, and plant the defect to see the case go red.
- 2026-10-27 (M065, used M073): sessioninfo 1.2.4 `session_info()` lists no base package, even one that is attached, and marks an attached package with `*` under the `*` of its header. A Quarto 1.10 knitr render of the template example attaches no package: knitr and rmarkdown are only loaded. `gh pr checks --watch --fail-fast` exited 1 with every check passed and one skipped, so read the check states, not the exit code.
- 2026-10-27 (M066, used M079): Windows file names cannot hold `*`, `?`, a line break, or a trailing space, which a folder name loses. There `file.exists()` stops with "file name conversion problem" on a path whose bytes are not UTF-8, and macOS refuses to make such a name. cli stops with "input string 1 is invalid UTF-8" on such text, so pass it through `show_text()`. `withr::local_envvar()` at a test file's top level holds for that file only.
- 2026-10-28 (M068, used M080): `R-CMD-check.yaml` and `pkgdown.yaml` have no path filter, so each push to a PR branch, a commit of `cairn/` files only included, reruns all 9 checks. On 2026-10-28 windows-latest took 10.7 and 11.1 minutes, past the 10-minute limit of one foreground `gh pr checks --watch`. Push tracking commits before the CI wait, or leave them unpushed until the merge.
- 2026-10-28 (M069, used M070): `pkgdown.yaml` runs on pull requests and pushes to main, so a branch push builds no site. `gh workflow run pkgdown.yaml --ref <branch>` builds one (the deploy job is skipped off main), and `gh run download <id> -n site` fetches it, kept 1 day. pkgdown 2.2 writes a relative navbar `href` with `../` on pages one folder down, and keeps the default right-side items when `_pkgdown.yml` sets only `left`.
- 2026-10-28 (M070, used M076): On macOS (R 4.6), Rscript writes each space in a script's path as `~+~` in its `--file=` argument, so a script that finds its own folder through `commandArgs()` turns `~+~` back into a space. After an error stops Rscript, R still deletes the session's `tempdir()`, so `tempfile()` folders need no cleanup on a failure path. `gregexpr(fixed = TRUE)` counts overlapping copies as one.
- 2026-10-28 (M071): Quarto 1.10.19's default listing sort puts items with a numeric `order` first, lowest first, ties by title, then the rest by title; a quoted `order` stops the render. R's yaml package reads YAML 1.1: `010` is 8, `1e3` and `1_000` are text, and 3000000000 is NA. `paste0(c(x, ""), lines)` recycles `x` onto every other line, so prefix only `lines[1]`.
- 2026-10-28 (M072, used M077): `system2()` quotes the program path with `shQuote()` itself, so a path quoted first is not found (status 127). With the default `stdout = ""` its output goes to the console, not to R, so `capture.output()` and testthat cannot read it; a test that needs Quarto's text uses `run_in()`. `file.exists()` ignores case on macOS and Windows, so match a name against `list.files()` to keep its case.
- 2026-10-28 (M073, used M074): usethis 3.2.2 `use_github()` names the repository after the folder. For about a minute after it pushes, GitHub's API can report another default branch, so `git_default_branch()` stops with "Default branch mismatch"; wait and run again. usethis asks yes/no through `utils::menu()`, so a scripted walk sets `options(rlang_interactive = TRUE)` and replaces `menu` in the utils namespace.
- 2026-10-28 (M074): `git remote add` plus a push leaves `refs/remotes/origin/HEAD` unset, and `git remote set-head origin --auto` sets it. `git symbolic-ref --short` prints `heads/<b>` beside a tag of the same name and `remotes/origin/<b>` beside a local branch `origin/<b>`, so read the full ref and cut the prefix. GitHub's new-release form takes `&target=<branch>` and decodes `%XX`. Wrap `git_in()` arguments holding `&` or `#` in `shQuote()`.
- 2026-10-29 (M075, used M076): R's PCRE match limit counts each lookahead and alternative tried per character. In a possessive loop over `<`, `<(?![/!])` read 4.8M `<`, but a second check per `<` (an alternation in the lookahead, two lookaheads, or an alternation in the loop) hit the limit at 4.4M. Keep one class lookahead per `<` and put rare forms in an outer loop. Test limits at fixed sizes; a size search over multi-MB strings takes minutes.
- 2026-10-29 (M076): `gregexpr(fixed = TRUE)` took 15 s for 360,000 matches in a 6 MB string where `perl = TRUE` took 0.01 s. A pattern of letter classes such as `</[Ss][Tt][Yy][Ll][Ee]` grew faster than the text (0.52 s for 20,000 matches, the literal 0.003 s), so match names in a copy lowered from raw bytes. `chartr()` took 1 s on 1 MB of non-ASCII text.
- 2026-10-29 (M076): `findInterval(x, vec)` turns an integer `vec` into a double on each call, so a loop of lookups into a long vector takes time that grows with the square of its length. Keep `vec` as a double and pass `checkSorted = FALSE`. An R loop over tag positions at about 3 µs a step ran 4 times slower than one `gsub()`, so walk runs of positions in one vectorized step.
- 2026-10-29 (M076, used M080): On windows-latest one `check_supplement()` call took 10.91 s where macOS took 2.33 s, so a timed test there needs about 5 times its macOS time. A bound with 2.5 times margin on macOS failed one of two Windows runs at the same head and passed the other.
- 2026-10-29 (M077, used M078): On Windows, `getwd()` keeps the 8.3 short form of a path given to `setwd()`, and Quarto 1.10 run from it leaves knitr chunk figures (`<report>_files/`) out of `docs/` with a "was not found" warning. `normalizePath(".")` gives the long form, and `utils::shortPathName()` makes a short path for a test. The windows-latest temp folder holds `RUNNER~1`, so short names exist there; stop rather than skip under `CI=true`.
- 2026-10-29 (M078, used M079): On Linux with R 4.6.1 in a UTF-8 locale, `list.files(pattern =)` leaves out a name that is not valid UTF-8, and `sub()` stops on one. Under `withr::with_locale(c(LC_CTYPE = "C"))` it lists the name and `sub()` works, but cli stops on the raw bytes. Quarto 1.10.19 renders a site holding such a report with exit 0 and no page for it. Only a Linux CI run shows these, since macOS refuses the name.
- 2026-10-29 (M079, used M080): cli builds a message before `suppressMessages()` drops it, so its stop "input string 1 is invalid UTF-8" on raw bytes still ends a call wrapped in it. `withr::with_locale()` warns only on a missing locale, so assert `Sys.getlocale("LC_CTYPE")` inside it. On ubuntu-latest (R 4.6), `tolower()` in the C locale lowers a non-UTF-8 name bytewise with no error. `gh run rerun <id> --failed` reruns only the failed jobs.
- 2026-10-30 (M080): On windows-latest (R 4.6.1), a testthat worker that crashed with exit code -1073741819 left no Windows Error Reporting `LocalDumps` dump, but a vectored exception handler that calls `MiniDumpWriteDump` in the process wrote one. `gh run view --log` prints nothing until every job of the run ends, so read one job with `gh api --allow-escape-sequences repos/<o>/<r>/actions/jobs/<id>/logs`.
- 2026-10-30 (M080): A testthat helper runs in the package namespace, where `.C("name")` looks only in the package's own DLL and stops with "not resolved from current namespace", so pass `getNativeSymbolInfo("name", dyn.load(dll))`. In PowerShell a bare `R` is the alias of Invoke-History, so call `R.exe CMD SHLIB`. A planted null write in a test ends the worker with the same exit code as the real Windows crashes.
